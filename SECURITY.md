# Security policy

If you find a security issue in the TCode Desktop preview, please **do not open a public issue**.

Use GitHub's private vulnerability reporting on this repository (Security tab →
Report a vulnerability). If that isn't available yet, open a normal issue with
the title "[Security] — please do not include details" and we'll reach out
privately right away.

Include the version, your Windows build, steps to reproduce, and any relevant logs.
We aim to acknowledge within 48 hours. Please give us a reasonable window to fix
an issue before disclosing it publicly.

Note: this repository contains installers only. Reports about the download page,
release artifacts, or SHA-256 digests are also welcome here.
